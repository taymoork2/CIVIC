Playing a story

Each step is a <civic-story> element. It shows a still first: the step's evidence, paths and design intent, drawn from the graph. A step that can be played offers to upgrade to a frame: the frame walk where the design links its frames, or the screen live in a journey canvas when the portal is built with one, and each recorded run replayed from the screen, played back from its tape (this portal was built with no tapes). Nothing plays until you ask.

Any page can host the same element: load civic-story.js and copy a step's <civic-story> markup.
