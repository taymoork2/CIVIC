# Unconfigured discovery example

This folder deliberately has no CIVIC manifest. It came from the journey engine's examples and moved here when CIVIC's copy of Example was removed (decision 0010, step 6). Connect it in the canvas through **Your projects → Connect existing app**, keep `src` as the source folder, then discover and generate the isolated screens.

The four HTML pages have real forms, links, a branch and return paths. Counter is a real React component with local state. Account requires a provider and remains an explicit coverage gap. No backend exists; generated navigation to Saved does not store a note in an application.
