# Rehearsal development snapshot

Rehearsal is the product; Laundry is the included reference integration. Read ../HANDOFF.md and docs/design/review-product/PRODUCT.md, project-onboarding.md, project-discovery.md and snapshot-cache.md. App/design-system files are integration context, not shell design authority.

Preserve identities, synthetic state and evidence boundaries; keep core/adapters separate. No production backend/account/model is required. Generated navigation, stale pictures and agent completion are not acceptance.

Use locked pnpm dependencies and scoped checks. Browser work belongs on a disposable host. Connected apps remain read-only unless the receiving user authorizes changes. Do not operate the original host's servers/settings/destinations merely because the handoff records them.
