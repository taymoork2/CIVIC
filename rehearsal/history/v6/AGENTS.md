# Rehearsal package orientation

Read HANDOFF.md, README.md, PACKAGE-VERIFICATION.md and source/docs/design/review-product/PRODUCT.md. This is an informational uncommitted snapshot with a reference app, not ownership of its original backend/runtime.

Keep core and app adapters separate. Preserve IDs/drafts/private stores; distinguish intent, source, preview, executed proof, design and device acceptance. Generated navigation, stale images, fixture jumps and agent completion are explicit, never promoted to product proof.

Accepted direction: one bounded canvas, Play default, optional Inspect, testable reversible proposals, actual screen pictures, horizontal journeys and vertical branches. Multiplayer readiness is required but unfinished.

Browser checks belong on a disposable host because they can save reviews/proposals and switch projects. No account/model/backend is needed for examples. Configure exact trusted agent destinations separately; dispatch needs human intent. Confirm new work scope with the receiving user; do not operate original machine paths or publish automatically.
