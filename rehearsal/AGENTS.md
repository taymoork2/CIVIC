# Rehearsal contributor instructions

Read `README.md`, `HANDOFF.md` and `source/docs/design/review-product/PRODUCT.md` before making changes. This package is an informational handoff, not permission to deploy, publish, message collaborators or overwrite external design projects.

Rehearsal is an independent product; Laundry App is the first adapter. Keep shell styles, product decisions and application domain behavior separate. The latest approved structure is one persistent canvas with selection, zoom and contextual panels. Earlier Workbench/Storyboard/Review mockups are historical proposals, not three required routes.

Preserve the private live run when browsing, opening panels and changing proposals. Fixture jumps require explicit draft protection. Never turn a jump, failed operation, inferred edge or historical screenshot into successful runtime evidence. Keep raw captured inputs allowlisted; never capture credentials or indiscriminate keystrokes.

Preserve durable capture/request identities across retries. Validate stable targets and expected proposal versions at the server boundary. A design proposal, its approval, application adoption, browser verification and physical-device acceptance are separate records and claims. Platform constraints require an explicit adaptation/limitation decision; they do not excuse silent drift.

Use the local Open Design desktop project and Claude Design as distinct design collaborators when available and authorized. Check ownership/revision before shared edits, use bounded briefs and wait for completed handoffs before integrating their active work. There is no automatic Figma or native-comment synchronization in this build.

Keep one accountable integrator and preserve unrelated work. Prefer existing components/helpers and minimal changes. Do not connect the synthetic review to a real Laundry backend. Keep the current server loopback-only until a separately designed identity, permission and deployment model is implemented.

Run proportionate checks listed in `README.md`; report exactly what passed, what was manual and what remains unverified. Do not claim full app coverage from the current specimen inventory. Document extraction and multiplayer work honestly rather than disguising adapter coupling with generic interfaces.
