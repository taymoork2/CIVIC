# CIVIC v0.1.0

The first release meant for people who didn't build it. It is a source release: clone, run, review.

## New

- `civic doctor` checks Node, git, pnpm and Chrome, and says how to fix each.
- `civic demo` installs on first run and opens the Notebook example, or your own app with `--project`.
- `civic desktop` opens the CIVIC desktop window on a local server of its own, downloading Electron on first run.
- A README that starts with what CIVIC is and how to try it, a [getting-started guide](../getting-started.md), and the [vision](../vision.md) as its own page.
- Every check now runs in a temp folder of its own that is removed afterwards, and never asks the signing key to sign throwaway commits.

## Also included

- Reviewing a running app through the overlay (`civic review-app`) and previewing a CIVIC worktree (`civic preview`).
- Records in the app's `.civic/` folder, with `civic move-store` for records kept in the old place.
- The review-to-agent loop through the CLI and the Claude Code and Codex plugin.

## Known limits

See [what doesn't work yet](../getting-started.md#what-works-today-and-what-doesnt). In short: no installer or signed app, macOS only tried, screen discovery is heuristic.
